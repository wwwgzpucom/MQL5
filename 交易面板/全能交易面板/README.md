# 全能交易面板（Nova Ultimate Trade Panel）

功能较全的图表交易面板：快速下单、挂单、图表拖线改 SL/TP、货币组批量开仓、移动止损、对冲/反手、按 Ticket 平仓、账户自动平仓与简单 Auto TP Bot 等。

适用于 **Exness** MT5。开户：[https://one.toexness.com/intl/zh/a/30852](https://one.toexness.com/intl/zh/a/30852)

## 文件

| 文件 | 说明 |
|------|------|
| `NovaUltimateTradePanel.mq5` | 单文件 EA → 复制到 `MQL5/Experts/` 后编译 |

## 主要能力

- 快速市价/挂单，手数可调
- 图表动态线调整止盈止损
- **货币组**一键多品种同向开仓（如 EUR 组）
- 移动止损（Trailing）
- 全部平仓 / 反手 / Hedge
- 按 Ticket 平仓；P2 详细持仓列表
- 账户盈利/亏损阈值 **自动全平**
- **Auto TP Bot**：盈利后续开，止损则暂停
- 账户盈亏、当日权益等交易信息区

## 安装

1. 将 `NovaUltimateTradePanel.mq5` 复制到 `MQL5/Experts/`
2. MetaEditor 编译
3. 拖到图表使用（切换面板页时若卡顿可稍等数秒）
