# MQL5

MT5/MQL5 trading panels catalog for XAUUSD and other instruments.

> 本仓库用于项目索引与分类，不复制外部项目代码。使用前请检查各项目许可证，并在模拟账户中回测和验证。

## 分类目录

- [通用下单 / 交易面板](./通用下单-交易面板/)
- [风险管理面板](./风险管理面板/)
- [拖线交易面板](./拖线交易面板/)

## 通用下单 / 交易面板

适合快速市价下单、挂单和基础交易操作，可挂载到 XAUUSD 图表：

- [TradingPanel](https://github.com/Kashu7100/TradingPanel) — MT5 交易辅助工具
- [AR Trading Panel for MT5](https://github.com/Andrukas8/AR_Trading_Panel_For_MT5) — 单窗口交易面板
- [MQL Trading Panel](https://github.com/SSinist3r/MQL_Trading_Panel) — MT4/MT5 通用交易辅助面板

## 风险管理面板

适合按账户风险计算手数、设置止损止盈、管理挂单和持仓：

- [mql5-risk-manager](https://github.com/Royatvand/mql5-risk-manager) — 风险仓位、挂单、SL/TP、移动止损和分批平仓
- [mt5-trade-panel](https://github.com/maxime-fintech/mt5-trade-panel) — 风险计算与订单管理面板
- [RiskDesk-MT5](https://github.com/keiwan-k99/RiskDesk-MT5) — MT5 风险与交易管理面板

## 拖线交易面板

适合在图表上拖动订单线，直观调整入场、止损、止盈和持仓管理：

- [mql5-trade-assistant](https://github.com/supertonka/mql5-trade-assistant) — 支持图表拖动控制的交互式交易助手
- [OrderCanvas](https://github.com/lichunboa/OrderCanvas) — 订单预览、可拖动订单线、保本和分批平仓

## XAUUSD 使用注意事项

- 确认经纪商的黄金合约大小、最小手数、最小变动单位和报价位数。
- 优先选择支持风险百分比、点值/货币风险和自动手数计算的面板。
- 实盘前先在模拟账户验证下单、止损、部分平仓和移动止损行为。
